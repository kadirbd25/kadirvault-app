## ✨ Key Features

- **Multi-Platform Support:** Download public Reels, videos, and clips from **Instagram**, **Facebook**, and **TikTok**.

- **Built-in Download History:** Keeps a local log of your recent downloads right inside the app.

## ⚡ Important Usage Notes

- **Server Wake-Up Delay:** KadirVault runs on a cloud server that automatically sleeps when idle. If you are the first person using the app after a quiet period, your **first download may take 45–60 seconds** while the server wakes up. All downloads immediately after that will start within seconds.
- **Public Links Only:** Private accounts, stories requiring login, and YouTube links are not supported.
- **Copyright Notice:** Please respect content creators and only download media that you have permission to save for personal offline use.
